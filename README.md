# Penjelasan

- Website ini di gunakan untuk test
- data yang di gunakan hanya fiktif
- database bersifat stand alone menggunakan sqlite3
- data yang di hapus tidak serta merta terhapus/hilang karna menggunakan fitur softdelete sebagai pertimbangan di lapangan
- website ini tidak memiliki middleware konfigurasi pengamanan website

# Installation

- Download file ini melalui github saya dan lakukan extract file
- jalankan file ini menggunakan menjalankan perintah 'php artisan serve'
- kamu dapat mengakses website ini menggunakan postman dengan memasukkan link url yang berjalan di terminal
